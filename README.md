# Proyecto Ultra V5.1 — Núcleo Isométrico Completo (offline)

## Abrir
- Doble clic en `index.html`, o subir toda la carpeta a GitHub Pages.

## Controles PC
- WASD / flechas: movimiento
- Tab: Paz/Batalla
- Espacio: atacar
- 1–6: seleccionar/lanzar hechizos
- E: usar/interactuar

## Incluye
- Cámara isométrica simulada en Canvas
- Paz/Batalla, targeting, autoacciones manuales, combate en movimiento
- 6 hechizos, vendas, pociones, aguante, bloqueos y muerte con cadáver
- Loot, seguro básico, oro transportado, reaparición y puntos de control
- Inventario, paperdoll y 13 slots de equipo
- 45 skills, cap 650 y gestión subir/mantener/bajar
- Recolección, procesamiento y crafting
- 5 ciudades, NPC, vendedores, banco, vivienda, cofres y puesto de venta
- Dungeons representadas, criaturas, mini bosses y boss
- Portales misteriosos y zonas delimitadas conceptualmente
- Guardado local

## Alcance
Es un prototipo offline funcional con gráficos geométricos de Canvas. No incluye red, servidores, otros jugadores ni PvP real.
