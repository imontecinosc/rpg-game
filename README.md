# Proyecto Ultra V5.0 — Reconstrucción modular

Prototipo local HTML5/Canvas para PC y móvil horizontal.

## Probar

Para GitHub Pages, sube todo el contenido manteniendo las carpetas. Abre `index.html` desde un servidor web. Los módulos JavaScript pueden bloquearse si abres el archivo directamente con `file://`.

## Incluye

- Estructura modular por datos, lógica, mundo, personaje, sistemas e interfaz.
- Movimiento táctil y WASD.
- Combate, magia y curación mientras te mueves.
- Enemigos, cadáveres y loot recuperable.
- Muerte con pérdida de inventario/equipo no asegurado y reaparición en punto de control.
- Inventario por viñetas, equipo funcional y 13 slots.
- 45 skills y cap provisional 650.
- Minería automática por golpes.
- Crafting básico con hierro, cobre y cuero de troll.
- Interfaz adaptable a móvil horizontal.

## Alcance

Esta versión es un núcleo jugable local. Housing, banco amplio, cofres domésticos, clanes, facciones, portales, criminalidad completa, vendedores persistentes y multijugador quedan preparados conceptualmente, pero no están implementados todavía.
