# Proyecto Ultra V5.7 — Base oficial para GitHub Pages

Prototipo estático modular con `index.html` en la raíz y rutas relativas. No requiere Node, React, backend ni proceso de compilación.

## Publicación

1. Extrae el ZIP.
2. Sube el contenido de `Proyecto-Ultra-V5.7-GitHub-Pages` a la raíz del repositorio.
3. En GitHub abre `Settings → Pages`.
4. Selecciona `Deploy from a branch`, rama `main` y carpeta `/root`.

Cambios principales:
- Avisos de subida de habilidad; niveles enteros muestran un aviso grande.
- Títulos por skill en 60, 70, 80, 90, 100, 110 y 120.
- Vendedor con selección, descripción y botón separado para comprar/vender.
- Banco con selección, descripción y botón separado para depositar/retirar.
- Dos ciudades separadas por una ruta extensa.
- Armas con poses de ataque diferenciadas.
- Personajes con rostro orientado en cuatro direcciones.
- Nombres visibles y coloreados según peligrosidad.
- Criaturas Exaltadas y Notables con estadísticas y loot superiores.
- Loot más variado para probar progresión.
- Renderer corporal compartido por jugador y humanos, con ropa por rol y NPC sin objetos en las manos.
- Equipamiento conectado a la apariencia del personaje y al paperdoll.
- Autoataque al seleccionar un hostil en modo Batalla.
- Cadáveres seleccionables con transferencia individual de objetos.
- Escudo como capa superior al mirar a la izquierda.

La sintaxis de todos los archivos JavaScript fue comprobada con Node.js.
