# Proyecto Ultra — Base Oficial V2

Entrega estática compatible con GitHub Pages.

## Publicación

1. Sube `index.html`, `game.js` y `renderer.html` a la raíz del repositorio.
2. En GitHub abre `Settings → Pages`.
3. Selecciona `Deploy from a branch`, rama `main` y carpeta `/root`.
4. Guarda y espera la URL de GitHub Pages.

No requiere Node, backend, compilación ni dependencias.
